# 🛡️ CyberillSec — Threat Intelligence and Cyber Threat Monitoring

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

**CyberillSec** is the Threat Intelligence pillar of the CYBERILL ecosystem. This repository houses **SENTRY**, our Security Monitoring and Threat Intelligence Platform.

## 🚀 Projects

| Project | Status | Description |
|---------|--------|-------------|
| **SENTRY** | 🏗️ Planning | Security Monitoring and Threat Intelligence Platform |
| Threat Feeds | 📋 Backlog | Real-time threat intelligence feed aggregator |
| CVE Tracker | 📋 Backlog | Automated CVE monitoring and alerting |
| SOC Dashboard | 📋 Backlog | Security operations center dashboard |

## 🏗️ Architecture

```
sentry/
├── threat-feeds/      # Threat intelligence feed collectors
├── cve-tracker/       # CVE monitoring and alerting
├── incident-mgmt/     # Incident management system
├── soc-dashboard/     # SOC visualization dashboard
├── threat-hunting/    # Proactive threat hunting tools
└── shared/            # Shared utilities and models
```

## 🛠️ Tech Stack

- **Backend:** Python / FastAPI
- **Database:** PostgreSQL + Redis
- **Message Queue:** RabbitMQ
- **Visualization:** Grafana
- **Deployment:** Docker / Kubernetes
